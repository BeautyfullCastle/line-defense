# 라인 디펜스 (Line Defense)

《Mini Metro》식 선 잇기 물류 관리 + 전선 방어를 결합한 웹 게임.
생산지와 요새를 노선으로 잇고, 마차 보급으로 몬스터 웨이브를 막아낸다.

## 실행

빌드 스텝이 없다. ES Module을 쓰므로 정적 서버로 열기만 하면 된다.

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

> `file://` 로 직접 열면 모듈 CORS 정책 때문에 동작하지 않는다.

## 구조

```
index.html         진입점 / HUD / 패널 마크업
css/style.css      스타일
src/balance.js     모든 밸런스 수치의 단일 원본 + 계수 공식
src/game.js        시뮬레이션 (생산·마차·요새·적·웨이브)
src/render.js      Canvas 2D 렌더링
src/ui.js          HUD·인스펙터·보상 모달
src/cheats.js      치트 메뉴 (밸런스 실시간 조정 포함)
src/main.js        입력 처리 및 메인 루프
```

## 조작

| 입력 | 동작 |
|---|---|
| 새 노선 그리기 → 건물 클릭 | 노선 연결 |
| 우클릭 / Enter | 노선 완성 (시작 건물 재클릭 시 순환선) |
| 건물 클릭 | 상세 정보 / 창고 확장 / 마차 편성 |
| Space | 일시정지 |
| 1 / 2 / 3 | 배속 x1 / x2 / x4 |
| Esc | 취소 |
| `` ` `` | 치트 메뉴 |

## 핵심 규칙 요약

- **노선에 마굿간이 최소 1개** 있어야 마차가 다닌다.
- 생산지는 **최대 적재량에 도달하면 생산을 멈춘다.** 마차가 비워줘야 재개된다.
- 요새는 **식량이 부족하면 공격 속도**가, **무기가 부족하면 공격력**이 떨어진다. 둘 중 하나라도 0이면 공격 불가.
- 석재는 성벽이 손상되면 자동 소모되어 1개당 100 회복한다.
- 요새가 하나라도 함락되면 게임 오버. 3웨이브마다 새 전선이 열리므로 물류망을 계속 확장해야 한다.
